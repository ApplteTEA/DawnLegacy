## High 개발 인계 — 라이벌 스타팅 v1 (2026-11-04)
- **구현:** 17타입 플레이어 선택에 대한 상성상 유리한 라이벌 타입 우선순위와 종별 랜덤 추첨 (`rival-system.js`).
- **구현:** 새 게임에서는 플레이어 룰렛 완료와 동시에 라이벌 결과를 저장하고, 별도 라이벌 룰렛 화면에서 결과 표시. 모험 기록에서 라이벌 타입/종 확인.
- **구현:** 기존 저장 게임에 라이벌 정보가 없으면 단 한 번 생성해 저장 키 `dawnLegacyCompleteV2` 유지.
- **검증:** 최신 `game.js` 데이터 기반 17타입 전체 후보·상성 테스트를 코드 실행으로 확인. `tests/rival-system.test.cjs`를 CI에 추가.
- **미검증:** 브라우저 UI 룰렛 직접 조작, 실제 Android/iOS, 세이브 복원 실환경 플레이. CI 배포 상태는 별도 확인 필요.
- **미구현:** 라이벌 NPC, 실제 첫 대결·재대결, 포켓몬 진화·성장, 스토리 연결.
- **Work 범위 보호:** 필드 렌더링/충돌/카메라/이동은 수정하지 않음. Work가 `game.js`를 변경한다면 최신 라이벌 저장 및 룰렛 로직을 반드시 병합해야 함.
- **변경 파일:** `rival-system.js`, `game.js`, `index.html`, `tests/rival-system.test.cjs`, `.github/workflows/pages.yml`. 작업 커밋은 `docs/CHANGELOG.md` 참조.

## 개발 현황
- **구현:** 주인공/NPC 5종, 독립 4방향·방향당 3프레임 PNG 아틀라스. 구형 이미지 덧칠/Canvas 캐릭터/배틀 축소 동행 제거.
- **구현:** 포켓몬 84종의 로컬 필드 걷기 에셋, 발 기준점·그림자·2배 정수 픽셀 배율, 직전 이동 경로 추적 및 보간.
- **검증 완료:** Chrome 390×844 세로 iframe에서 네 방향 이동, 코너 추적, 브케인/치코리타/리아코, NPC 대화, 저장·재로드, 트레이너전 진입·불꽃세례·상대 턴(HP 18→11).
- **검증 완료:** 84종 에셋 누락/빈 방향 검사, 인물 방향별 3개 고유 프레임, 경로/방향/세이브 이관 단위 검사, JS 문법 검사.
- **미확인:** Android/iOS 실기기, 포획 전체 흐름 및 전체 게임 진행 회귀, 모든 종의 개별 육안 확인. 정상 색상 필드 에셋만 제공하며 이로치 전투/게임 규칙은 보존.
- 기존 전투·포획·파티·배지·스토리 로직은 변경하지 않음. 기존 세이브 키와 버전 유지.
- 에셋 출처/라이선스 및 공식 원작 권리 구분: CHARACTER_ASSET_CREDITS.md.
- 코드 반영 및 배포 결과는 아래 작업 인계와 CHANGELOG에서 별도 기록.
