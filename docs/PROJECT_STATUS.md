# 프로젝트 현황

기준일: 2026-11-03
저장소: https://github.com/ApplteTEA/DawnLegacy
게임: https://appltetea.github.io/DawnLegacy/

## 개발 현황
- 현재 저장소에서 index.html, bootstrap.js, game.js, world-v2.js 존재 확인
- 브라우저 Canvas 기반 필드와 게임 로직이 존재함
- 모바일 방향키, 배틀 및 포켓몬 데이터 등 기존 기능은 회귀 방지 대상
- 그래픽 전면 재구축을 Work에 요청했으나 사용량 제한으로 진행 상태 확인 불가
- **운영 가정:** 이후 스토리 설계는 그래픽 작업이 끝났다는 가정으로 진행
- **검증 사실:** GitHub에 그래픽 최종본 반영 및 모바일 화면 품질은 확인하지 못함. 가정을 검증 완료로 기록하지 않는다.

## 확정된 기획
- 정통 체육관/챔피언 모험과 후반 미스터리의 결합
- 최종 전설 포켓몬: 아르세우스
- 플레이어: 타입 선택 → 해당 타입 후보 포켓몬 랜덤 룰렛
- 라이벌: 플레이어 타입에 강한 타입 자동 결정 → 해당 타입 포켓몬 랜덤 룰렛 → 최초 결과 고정
- 기획/코드/검증을 Markdown 문서로 지속 관리

## 제안 단계
- 아우라 지방, 새벽마을, 8개 체육관 도시와 5막 이야기
- 시온, 해솔 박사, 루나, 이클립스단 및 카이론
- 여명석과 체육관 배지의 관계
- 아르세우스의 엔딩 이후 포획
- 상세 내용은 WORLD_LORE.md, STORY.md, GAME_DESIGN.md 참조
