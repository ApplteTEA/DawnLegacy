# 작업 우선순위

## P0 — Work 그래픽 결과 확인
- [ ] Work의 그래픽 재구축 커밋/변경 파일 확인
- [ ] 주인공 네 방향 독립 스프라이트와 방향별 3프레임 이상 걷기 확인
- [ ] NPC 스타일과 동행 포켓몬 종류별 필드 스프라이트 확인
- [ ] Android 세로 화면에서 이동/방향/동행/크기/발 위치 검증
- [ ] 게임 기존 기능 회귀 검사
> 스토리 개발 일정에서는 그래픽 작업 완료를 가정할 수 있으나, 이 체크리스트는 증거 확인 전 완료 처리하지 않는다.

## P1 — 확정 시스템
- [ ] 현재 스타팅 타입 선택/룰렛 구현 분석
- [ ] 17개 타입에 대한 라이벌 상성 후보 결정 규칙 확정
- [ ] 라이벌 포켓몬 후보 필터링 및 룰렛 구현
- [ ] 라이벌 결과 저장 및 기존 세이브 마이그레이션
- [ ] 복합 타입, 복수 약점, 후보 없음, 동일 종 중복 등 예외 테스트
- [ ] 라이벌 재대결 및 스타팅 진화 연동

## P2 — 스토리 1차 플레이 구간
- [ ] 제안된 아우라 지방/등장인물/도시 설정 사용자 확정
- [ ] 새벽마을 해솔 박사 이벤트
- [ ] 첫 스타팅 선택과 시온 라이벌 첫 대결
- [ ] 1번도로 탐험/야생 포켓몬/트레이너전
- [ ] 푸른잎시티 체육관/관장/배지
- [ ] 첫 번째 이상 현상 및 이클립스단 복선

## P3 — 중후반
- [ ] 체육관 2~8 및 각 도시 연결
- [ ] 여명석/고대 유적/이클립스단 메인 퀘스트
- [ ] 아르세우스 이벤트/보스전
- [ ] 사천왕/챔피언/엔딩
- [ ] 2회차 포획 및 후일담

## 문서 유지
- [ ] 작업마다 PROJECT_STATUS/CHANGELOG/TODO 갱신
- [ ] 시스템 변경 시 GAME_DESIGN/ARCHITECTURE 갱신
- [ ] 스토리 확정/변경 시 STORY/WORLD_LORE 갱신
