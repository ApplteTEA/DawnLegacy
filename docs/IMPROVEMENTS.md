## 관리 방식

각 작업은 `DL-###` 고유 ID, 중요도(P0~P3), 담당(High/Work), 상태, 재현 방법, 관련 파일, 완료 기준과 검증 증거를 가진다.
- 상태: 제안 / 대기 / 진행 중 / 구현 완료(검증 대기) / 검증 완료 / 종료 / 차단됨 / 재발.
- 사용량 제한으로 시작하지 못한 Work 작업은 `대기(Work 사용량 제한)`.
- 완료 시 근거가 되는 커밋, 테스트, 실제 실행 환경을 기록. 미확인 항목을 완료 처리하지 않는다.
- 연관 과제가 하나의 Work 작업으로 함께 진행되더라도, 항목별로 완료 여부를 판단한다.

### DL-001 — 나무/건물/물/울타리 충돌 정합성
- **우선순위:** P0
- **담당:** Work (대기)
- **상태:** 대기(Work 사용량 제한)
- **보고된 현상:** 플레이어가 나무나 장애물을 통과함.
- **참고 파일:** `game.js`, `world-v2.js`, 맵/이동 관련 모듈 (변경 전 최신 소스 확인).
- **개선 방향:** 지형 렌더링·충돌이 공통 맵 데이터/장애물 데이터 참조. NPC도 통과 불가.
- **완료 기준:** 나무/건물 벽·모서리/물/울타리/NPC 충돌, 도로·일반 잔디·야생 풀숲 통과, 장애물 경계·맵 경계 테스트 통과.
- **검증 증거:** 미등록. Work 처리 후 커밋 및 실행 환경 기입.

### DL-002 — 연속 이동 중 순간이동/좌표 튐
- **우선순위:** P0
- **담당:** Work (대기)
- **상태:** 대기(Work 사용량 제한)
- **보고된 현상:** 방향키 이동 도중 갑자기 좌표가 바뀌거나 순간이동처럼 보임.
- **참고 파일:** `game.js`, `field-actors.js`, `world-v2.js`, 입력/카메라 관련 로직.
- **개선 방향:** 논리 타일 좌표·화면 보간·입력 반복·지역 전환·저장 복원 경로 구분. 원인을 확인하고 수정.
- **완료 기준:** 빠른 연속 입력/역방향 전환/장애물 충돌 직후/장시간 누름/지역 경계/세이브 재로드 테스트에서 비정상 점프 없음. 동행 포켓몬 경로 유지.
- **검증 증거:** 미등록.

### DL-003 — 마을/필드 배경 픽셀아트 품질
- **우선순위:** P1
- **담당:** Work (대기)
- **상태:** 대기(Work 사용량 제한)
- **보고된 현상:** 집 크기와 디자인이 단조롭고, 나무가 규칙적으로 반복되며, 풀/도로가 단색·직선 중심.
- **참고 파일:** `world-v2.js`, 에셋/맵 관련 파일.
- **개선 방향:** 이전 Work가 생성한 게임 화면을 기준으로 건물/풀/나무/도로/연못/표지판 등의 일관된 픽셀아트 에셋과 배치 개선. 다른 사람/포켓몬 에셋은 보존.
- **완료 기준:** 건물별 특징 식별, 배경과 인물 크기/픽셀 밀도 일치, 반복 패턴 개선, 통행 가능 지형/오브젝트 배치와 충돌 영역 정합성 확인.
- **검증 증거:** 미등록. 개선 전후 화면 비교 필요.
