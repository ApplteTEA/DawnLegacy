> **상태:** 2026-11-04 **승인 전 제안 설계**. 게임의 실제 지도가 아니다. 지도명·좌표·지역 레벨은 신규 기획값이며 사용자 승인 전 확정으로 표기하지 않는다.

## 1. 맵 그래프 — 메인 경로
```text
[M00 새벽마을]
      │ R01 1번도로
[M01 푸른잎시티] ─ D01 이슬숲(숲 사건)
      │ R02 숲빛길
[M02 은빛항구] ─ D02 항구 창고 / F01 등대
      │ R03 해안도로
[M03 번개시티] ─ D03 발전소
      │ R04 바람언덕길
[M04 안개마을] ─ D04 고대 유적 / F02 기록관
      │ R05 붉은계곡로
[M05 홍염시티] ─ D05 폐쇄 연구동
      │ R06 눈마루길
[M06 설화시티] ─ D06 설산 기록관
      │ R07 철빛협곡
[M07 철벽시티] ─ D07 이클립스단 본거지
      │ R08 하늘오름길
[M08 천공시티] ─ D08 구름 협곡 ─ D09 하늘신전(메인 클라이맥스)
      │ R09 챔피언로드
[M09 포켓몬리그] ─ L01 사천왕·챔피언 경기장

[2회차] M04 ─ P01 봉인서고 / M01 ─ P02 라이벌 광장
         M08 ─ D09 하늘신전 재방문 / M09 ─ P03 배틀탑
```

### 지도 불변 규칙
- **주 진행은 선형, 재방문은 비선형.** 새로운 마을로 가는 정문만 이벤트/배지로 통제하며, 지나온 마을과 야생 서식지는 언제든 돌아갈 수 있다.
- 지역 봉쇄는 '관장이 모호하게 막는다'가 아닌 **NPC 대사·지도 아이콘·퀘스트 로그**에서 필요한 조건을 설명한다.
- 새로운 맵/입구를 열 때 복귀 출구를 항상 함께 제공한다. 중앙 세이브 포인트 및 패배 귀환 장소를 일관되게 정의.
- 스토리 던전 진입 전 회복/아이템 구매 경로 보장. 보스전에서 패배해도 장치/문이 영구 잠기지 않음.
- 모든 출입구는 방향이 있는 두 개의 명시적 portal로 연결하며, 도착 스폰은 벽/물/이동불가 타일이 아님을 자동 검사.

## 2. 맵 엔트리 규격 (개발 계약)
맵 데이터는 코드에서 하드코딩된 x 구간 대신 독립된 `mapId`를 사용한다. 아래 필드는 **구현 요구 사양**이다.

| 필드 | 의미 | 예시 |
| --- | --- | --- |
| `id` | 전역 유일·변하지 않는 ID | `M01` |
| `displayName` | 화면 표기 | 푸른잎시티 |
| `size` | 정수 타일 가로×세로 | 40×30 |
| `biome` | 타일 팔레트/조명 룩업 | forest |
| `collisionLayer` | 지형별 통행 불가와 오브젝트 충돌 | 물/나무/벽/울타리 |
| `portals` | 양방향 링크/스폰/조건 | `R01→M01` |
| `npcs` | 고유 NPC ID, 상호작용 조건 | `NPC_SOLBI` |
| `encounters` | 레벨/확률/종/장소/시간 | `R01_GRASS` |
| `entities` | 스토리 오브젝트, 상태/가림 관계 | `OBJ_F01_SIGN` |
| `music` | 지역/장면/전투의 음향 ID | `BGM_CITY_FOREST` |
| `spawn` | 정상 귀환, 실패 귀환, 최초 진입 좌표 | `from_R01` |

제안 기본 타일은 현행 `field-manifest.js`/렌더러의 **24px**를 출발점으로 삼되, Work의 필드 구조 개선이 끝난 후 결정한다. 스크롤/줌은 타일 좌표와 렌더링 좌표를 분리한다. 맵 크기 제안: 시작 마을 32×24, 일반 도시 40×30, 루트 56×24, 던전 한 층 28×24. 실제 타일 크기·에셋 라이선스는 Work 결과를 우선 검증한다.

### 포털/좌표 검증 체크
1. 모든 `portal.destinationMapId`가 실존하는지 검사.
2. 도착 스폰이 그 맵 안이고 보행 가능한 타일인지 검사.
3. 필수 메인 이벤트 진행 상태에서 양방향 왕복/회복이 가능한지 검사.
4. 각 지도에서 모든 필수 NPC까지 통행 가능한 연결요소가 있는지 BFS로 검사.
5. 진행 잠금 조건이 만족되지 않았을 때도 빠져나갈 수 있는지 검사.

- **진화형 야생 출현:** 스토리상 흔하면 안 되는 최종 진화형은 포스트게임 및 고레벨 서식지에서만 제한.

## 6. 중복되지 않는 퀘스트용 오브젝트 배치
- `OBJ_M00_BOARD` 연구소 앞 안내판 → 타입 챌린지, 첫 출발 동선.
- `OBJ_R01_PARCEL` 배달 주머니 → S01 배달 서브퀘스트, 영구 복구 가능.
- `OBJ_D01_RING` 금속 고리 → 최초 조사에서만 '핵심 단서 1' 획득.
- `OBJ_D02_CRATE` 봉인 화물 → '핵심 단서 2', 해안 경비대 보고 후 다음 맵 개방.
- `OBJ_D03_LOG` 전력 기록 → '핵심 단서 3', 루나에게 지도로 전달.
- `OBJ_D04_CORE` 여명석 핵 → 스토리 중요 아이템 1개, 버리기/판매 불가.
- `OBJ_D05_REPORT` 10년 전 실험 보고서 → 카이론/윤하 과거 복선.
- `OBJ_D06_TABLET` 설산 기록판 → 공명기의 중단 순서.
- `OBJ_D07_KEY` 세라 통제 키 → 신전 세 거점 차단.
- `OBJ_D09_SWITCH_[1..3]` 세 공명기 차단 장치 → 순서대로 동작, 사후 재방문에서 비활성.
- `OBJ_M09_REGISTER` 리그 참가 접수 → 배지·사천왕·챔피언전 확인.

## 7. 월드 전환과 충돌 시스템에 대한 인계
- Work는 배경·이동·충돌 재구축을 대기 중. **본 문서만으로 현재 필드를 건드리거나 타일 데이터를 생성하지 않는다.**
- Work 결과가 공통 타일맵 형식이면 `collisionLayer`/portals 규격을 해당 형식에 맞춰 매핑. 맵마다 렌더링·충돌 두 개의 진실이 생기지 않게 한다.
- 모든 맵은 `mapId + local(x,y)`를 사용하고, 카메라 좌표·화면 픽셀 좌표와 분리. 현재의 전역 `x` 위치만으로 지역을 판정하는 시스템에서 이관해야 한다.
- 주인공/팔로워·NPC 스프라이트 4방향 애니메이션 및 현행 24px 원칙은 기능 회귀 검사 후 재사용.
- 대규모 지도 생성 시 IP 문제: 오리지널 타일/사용권 확인한 에셋 우선. 원작 게임 맵의 복제/추출물을 기획의 필수 에셋으로 요구하지 않는다.
